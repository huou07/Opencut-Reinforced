# Archive

Last reviewed: 2026-10-26

Everything here is history. It preserves dated decisions, delivery records and
receipts so a later reader can check how a conclusion was reached. Nothing here
selects current work or states current truth; use [AGENTS.md](../../AGENTS.md) to
reach the live document for a subject.

| Path | What it holds |
|---|---|
| [legacy/](legacy/) | the pre-2026-10-26 document set: architecture plan, phase plan, product roadmap, testing/tooling records, delivery logs, superseded design and policy docs |
| [evidence/](evidence/) | dated local acceptance receipts for Linux, Android and transcription work |
| [execution/](execution/) | the paused execution lock: checkpoint graph, ledger, phase specs, evidence policy and JSON receipts |
| [prompts/](prompts/) | retired owner mission briefs |

Two practical cautions:

- A statement in this tree may have been true only for the machine, source
  revision and date it names. Recheck locally before relying on it.
- Do not edit an archived record to match current behaviour. Add a current
  document instead; the archive is evidence of what was decided or observed.
