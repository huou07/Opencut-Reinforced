# Feature documentation

Feature bundles are defined in [DOC_ROUTING.json](../DOC_ROUTING.json).
They select canonical sections of existing documents rather than duplicate
contracts. New substantial features may use up to four canonical documents
here (contract, architecture, testing, justified troubleshooting); a small
feature needs only a README. Every feature document must be routed or explicitly
on demand. Do not create directories for unimplemented features.

See [documentation routing](../DOCUMENTATION.md) for commands and authority.
