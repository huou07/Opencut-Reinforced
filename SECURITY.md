# Security Policy

The project has no released stable versions yet.

## Reporting a vulnerability

Do not report vulnerabilities in a public GitHub issue. Prefer [GitHub Private Vulnerability Reporting](https://github.com/huou07/Opencut-Reinforced/security/advisories/new) when it is enabled for this repository. If private reporting is unavailable, do not publish sensitive vulnerability details in a public issue.

Please include, where possible:

- affected version or commit
- impact
- reproduction steps
- a proof of concept, if safe to share
- a mitigation, if known

We will review reports as maintainer capacity allows and prioritize issues based on impact and exploitability.

If credentials have been exposed, revoke or rotate them immediately. Removing leaked credentials from the repository is not sufficient.
