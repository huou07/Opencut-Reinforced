# Showcase pack

A one-minute product or feature film: motion-graphic beats over measured
narration, one music bed, real caption clips. This is the default style for a
complete short video; the machinery is
[`../../video-pipeline/README.md`](../../video-pipeline/README.md).

## Numbers

| Property | Value |
|---|---|
| Length | 55–75 s |
| Canvas | 1920×1080, 30/1 |
| Beats | 6–8 scenes, 4–8 s each |
| Narration | 17–20 characters/s, 180 wpm |
| Speech coverage | 45–60 % of the runtime |
| Gaps between lines | 250 ms |
| Captions | 26 pt, bottom, offset −420 px |
| Music | −9 dB under speech |

## Read in this order

1. `story.md` — the beat arc and what each beat must prove.
2. `script.md` — sentence length and the characters-per-second budget.
3. `motion.md` — palette, camera and animation density.
4. `voice.md` — rate, gaps and voice choice.
5. `edit.md` — cut rhythm and music level.
6. `captions.md` — cue length, size and position.

## Non-negotiables

- One idea per beat; a beat that needs two headlines is two beats.
- The first three seconds carry the hook; no logo-only opening.
- Every claim is visible on screen, not only spoken.
- The last beat lands the product identity and one next action.
- Captions are clips, never burned into a render.
