# Style packs

Method-only packs for making a video look and sound like a proven one. A pack
carries timing, palette, camera, beat shape, cue rules and voice settings — never
narration text, names, claims or footage.

## Packs

| Pack | For | Path |
|---|---|---|
| Showcase | a one-minute product or feature film | `showcase/README.md` |
| Documentary | a multi-minute chaptered story | `../cinematic-story/STYLE.md` |

The documentary entry is the pre-existing cinematic style, kept in place until it
is split into the six-file shape.

## Contract

A pack is a directory with `README.md` and six method files: `motion.md`,
`story.md`, `script.md`, `voice.md`, `edit.md`, `captions.md`. Every number has a
unit and was measured on a real cut. If a rule only makes sense for one topic, it
belongs in that video's notes, not in a pack.

## Use

Read the pack README, then only the file the current decision needs. Keep the
canvas, frame rate and structural numbers; adapt speed and length to the
language and target duration. Write new content.

## Promote

When the user judges a video good and the approach is repeatable, copy
`showcase/` to `templates/styles/<slug>/`, replace the numbers with measured
ones, strip the content, add a row above and route the pack from `AGENTS.md`.
The full rule is in `../../docs/style-packs.md`.
